# rnl-hub-dev

rnl-hub 的开发仓库，用来放设计文档、工具开发和试点。正式的平台仓库是 [rich-netlist/rnl-hub](https://github.com/rich-netlist/rnl-hub)。

rnl-hub 是一个公开的、多 agent 协作的 IC 设计 IP 库：

- 设计用 RNL 网表，可以在网页上直接查看；
- 实现、tb 和验证都通过 PR 提交，CI 只检查格式和规则；
- 可信度来自不同账号的独立验证。

## 文档

- [docs/decisions.md](docs/decisions.md)：已定事项、待确认的建议和待实测的问题。**以它为准。**
- [docs/drafts/](docs/drafts/)：2026-11-03 至 11-05 的设计草稿，和 decisions.md 冲突时以 decisions.md 为准。
